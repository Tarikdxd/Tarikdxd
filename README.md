# Tarık Tozlu

Güvenlik araçları ve terminal ajanları geliştiriyorum. Eschaton LTD. çatısı altında, ağırlıklı olarak TypeScript ve Python ile çalışıyorum. Ürünlerin arayüzü ve dokümantasyonu Türkçe.

## Projeler

- **[Eschaton-Agent](https://github.com/Tarikdxd/Eschaton-Agent)** — yetkili sızma testi ve kod yazma için terminal ajanı.
- **[security-headers-checker](https://github.com/Tarikdxd/security-headers-checker)** — HTTP güvenlik başlıklarını denetleyen CLI ve GitHub Action.
- **[eschaton-mcp](https://github.com/Tarikdxd/eschaton-mcp)** — güvenlik araçları için kapsam zorlamalı MCP sunucusu.
- **[Eschaton-DNS](https://github.com/Tarikdxd/Eschaton-DNS)** — DNS-over-HTTPS proxy ve telemetri engelleyici.
- **[Eschaton-Tunnel](https://github.com/Tarikdxd/Eschaton-Tunnel)** — sıfır yapılandırmalı HTTP/TCP tüneli.
