## Hakkımda

- **Eschaton LTD.** çatısı altında yetkili sızma testi ve hata avcılığı için araçlar geliştiriyorum.
- Terminal ajanları, ağ araçları, MCP entegrasyonları ve otomasyon üzerine çalışıyorum.
- **Security, privacy.** Yerel, denetlenebilir ve minimum veri toplayan tasarımlar.

## Projeler

- **[Eschaton-Agent](https://github.com/Tarikdxd/Eschaton-Agent)** `v1.0.0` — insan denetimli terminal ajanı; Türkçe arayüz, 36 beceri, MCP.
- **[security-headers-checker](https://github.com/Tarikdxd/security-headers-checker)** `v0.2.0` — CSP/HSTS/CORS denetimi, puanlama, SARIF ve GitHub Action.
- **[eschaton-mcp](https://github.com/Tarikdxd/eschaton-mcp)** `v0.2.0` — nmap/httpx/ffuf/sqlmap/nuclei için kapsam zorlamalı MCP sunucusu.
- **[Eschaton-DNS](https://github.com/Tarikdxd/Eschaton-DNS)** — DNS-over-HTTPS proxy ve telemetri engelleyici.
- **[Eschaton-Tunnel](https://github.com/Tarikdxd/Eschaton-Tunnel)** — sıfır yapılandırmalı HTTP/TCP tüneli.
