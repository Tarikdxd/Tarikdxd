# Tarık Tozlu

Yapay zeka ajan orkestrasyonu, güvenlik araçları ve gizlilik odaklı ağ yazılımları geliştiriyorum. **Eschaton LTD.** çatısı altında, ağırlıklı olarak Python ve TypeScript ile çalışıyorum. Ürünlerin arayüzü ve dokümantasyonu Türkçe öncelikli.

## Projeler

- **[Eschaton-Agent](https://github.com/Tarikdxd/Eschaton-Agent)** — Evrensel Antigravity Köprüsü & %10 Kullanım Kalkanlı Yardımcı Ajan Orkestratörü; Qoder, OpenCode ve Claude Code gibi ajanların yerel Antigravity'ye bağlanıp onu yönetmesini sağlar ([canlı site](https://tarikdxd.github.io/Eschaton-Agent/)).
- **[eschaton-mcp](https://github.com/Tarikdxd/eschaton-mcp)** — `nmap`, `httpx`, `ffuf` ve `sqlmap` için kapsam zorlamalı (fail-closed) MCP sunucusu.
- **[security-headers-checker](https://github.com/Tarikdxd/security-headers-checker)** — HTTP güvenlik başlıklarını denetleyen, puanlayan ve SARIF çıktısı üreten Bun CLI ve GitHub Action.
- **[Eschaton-DNS](https://github.com/Tarikdxd/Eschaton-DNS)** — Canlı terminal TUI'a sahip ultra hafif DNS-over-HTTPS (DoH) proxy ve telemetri engelleyici.
- **[Eschaton-Tunnel](https://github.com/Tarikdxd/Eschaton-Tunnel)** — Sıfır yapılandırmalı yerel HTTP/TCP ters proxy ve tünelleme CLI'ı.
- **[gh-profile-kit](https://github.com/Tarikdxd/gh-profile-kit)** — GitHub profil kartlarını kendi reponda üreten, dış servise bağımlı olmayan şablon.

## Türkçe Kaynaklar & Şablonlar

- **[awesome-turkish-security](https://github.com/Tarikdxd/awesome-turkish-security)** — Türkçe açıklamalı, bağlantıları düzenli doğrulanan siber güvenlik kaynakları listesi.
- **[turkish-ctf-writeups](https://github.com/Tarikdxd/turkish-ctf-writeups)** — Gerçek, yasal laboratuvarlardan Türkçe CTF ve zafiyet analizi writeup'ları.
- **[bug-bounty-report-templates](https://github.com/Tarikdxd/bug-bounty-report-templates)** — Türkçe alan etiketli bug bounty rapor şablonları, CVSS başvurusu ve SARIF örneği.
