## 🛡️ About Me

I design and build **high-performance systems**, **privacy-first network proxies**, and **autonomous agent orchestrators**. Focused on zero-trust architectures, protocol reverse engineering, and developer tooling.

- 🔭 **Featured Open Source Projects:**
  - [**Eschaton-Code**](https://github.com/Tarikdxd/Eschaton-Code) — Production-grade multi-agent orchestration framework for autonomous LLM teams (TypeScript).
  - [**Eschaton-Tunnel**](https://github.com/Tarikdxd/Eschaton-Tunnel) — Instant, zero-config localhost to internet reverse proxy CLI (Free ngrok alternative).
  - [**Eschaton-DNS**](https://github.com/Tarikdxd/Eschaton-DNS) — Lightweight DNS-over-HTTPS (DoH) proxy and telemetry/tracking sinkhole.
  - [**Discord-Token-Manager**](https://github.com/Tarikdxd/Discord-Token-Manager) — Multi-account management and ghost voice coordinator with CustomTkinter GUI.
- ⚡ **Specialties:** Network Protocol Reverse Engineering (ENet, DNS, HTTP/2), Low-level Scripting, Python, TypeScript, Security Research.
