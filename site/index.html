Dört Ana Odak

Geliştirdiğim projeler; ajan orkestrasyonu, kapsam zorlamalı güvenlik otomasyonu, ağ gizliliği ve Türkçe kaynak üretimi etrafında şekilleniyor.

01 / CO-AGENT BRIDGE

Ajan Orkestrasyonu & MCP

Qoder, OpenCode, Claude Code ve Cursor gibi ajanları yerel Antigravity masaüstü uygulamasına bağlayan, %10 kullanım kalkanlı ve canlı benchmark yönlendirmeli köprüler.

02 / OFFENSIVE & APPSEC

Güvenlik Denetimi & Araçlar

nmap, httpx, ffuf ve sqlmap için fail-closed kapsam zorlamalı MCP sunucuları; HTTP güvenlik başlıklarını SARIF çıktısıyla puanlayan Bun CLI ve GitHub Action'lar.

03 / NETWORK & PRIVACY

Ağ Tünelleme & DNS Gizliliği

Canlı terminal TUI arayüzlü hafif DNS-over-HTTPS (DoH) telemetri engelleyicisi ve sıfır yapılandırmalı açık kaynak HTTP/TCP ters proxy tünel araçları.

04 / TURKISH OPEN SOURCE

Türkçe Güvenlik Ekosistemi

Türkçe açıklamalı siber güvenlik kaynak listeleri, yasal laboratuvarlardan CTF writeup'ları ve CVSS/SARIF uyumlu bug bounty rapor şablonları.
